# Dayfill

한 해 동안 살아온 시간을 배터리처럼 채워 보고, 하루의 사진과 짧은 기록을 기기에 남기는 모바일 중심 PWA입니다.

## 웹앱

**https://yseungae.github.io/dayfill/**

## 주요 기능

- 현지 날짜 기준 연간·월간 진행률과 남은 금요일 계산
- 실제 배터리를 닮은 segmented battery UI
- 하루 한 장의 사진과 짧은 기록 저장·수정·삭제
- IndexedDB 기반 기기 내 영구 저장 및 연도별 데이터 구조
- 한국어/English UI 전환
- 설치 및 오프라인 실행이 가능한 PWA

## 로컬 실행

정적 파일 서버로 이 폴더를 열면 됩니다.

```bash
npx serve .
```

브라우저 저장소에만 기록이 남으므로 다른 기기와 자동 동기화되지 않습니다.
